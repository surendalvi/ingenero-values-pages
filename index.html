How filters and totals are calculated
  • Each populated repository row counts as one case entry. The case ID identifies the product. A paired scenario has a UC entry and a matching X360-UC entry. The shared scenario count counts the pair once.
  • Explorer applies the selected filters together. Results and overview charts recalculate from the same matching entries. Industry count follows distinct workbook labels, including Cross-industry.
  • IngeneroX annual value sums the original annual case amounts. Registered and potential amounts sum the IngeneroX360AI planning allocations separately. The workbook’s stated portfolio figures remain separate from individual allocations.
  • Module catalogue usage is the count in the workbook. The optional module entry points search the repository. Evidence labels and approval flags come directly from the current repository rows.
